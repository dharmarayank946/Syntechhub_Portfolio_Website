# Nagalambika D Koralli - Personal Introduction Page (Task 2)

A single-page personal introduction website created using HTML5 and CSS3 for VEDA Technology Web Development Internship (Task 2).

## 🌟 Features
- **Soft Pastel Red Aesthetic**: Custom light theme palette (`#FFF8F7`, `#D98282`, `#F3C6C6`, `#C96F6F`).
- **Semantic HTML5 & Pure CSS3**: 100% JavaScript-free, framework-free web layout.
- **Clean Structure**:
  - Hero section with professional profile photo
  - About Me intro & 5th semester CS student details
  - Internship Experience (Mastertej & ElevanceSkills)
  - Achievements & Hackathons (Bug Hunt First Prize & CodeMyFYP Hackathon)
  - Creative Side & UI/UX Design exploration
  - Development Journey pipeline
  - Career Goal: Scientist/Engineer 'SC' in ISRO
  - Skills breakdown & Clickable Contact links
- **Responsive Layout**: Fluid design across Desktop, Tablet, and Mobile screens.

## 🛠️ Built With
- **HTML5** - Semantic layout structure
- **CSS3** - Custom variables, CSS Grid, Flexbox, hover transitions, and responsive media queries
