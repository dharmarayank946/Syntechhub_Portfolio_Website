# Nagalambika D Koralli - Personal Tribute & Portfolio Website

A personal tribute and storytelling portfolio website for Nagalambika D Koralli — Student, Web Development Intern, and UI/UX Learner.

## 🌟 Features
- **Modern Soft-Lilac Theme**: Custom aesthetic with smooth pastel color palette.
- **Interactive Storytelling**: Interactive sections showcasing journey, achievements, projects, and technical skills.
- **Dynamic UX**: Smooth scrolling navigation, micro-interactions, responsive mobile menu, and fluid modal viewer.
- **Contact & Profiles**: Fast access to GitHub, LinkedIn, and email contact links.

## 🛠️ Built With
- **HTML5** - Semantic structure and layout
- **CSS3** - Custom variables, glassmorphism, animations, and responsive flexbox/grid layouts
- **JavaScript (ES6+)** - Dynamic DOM manipulation, scroll observers, modal interactions, and menu behavior

## 🚀 Local Development
To run this project locally, simply open `index.html` in any web browser or serve it using a local HTTP server:

```bash
# Using python
python -m http.server 8000

# Using npx http-server
npx http-server . -p 8080
```
